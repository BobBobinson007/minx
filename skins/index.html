Skin einreichen

Du hast einen eigenen Skin gebaut und willst ihn auf den Server bringen? Schick ihn an einen Admin im Spiel oder per Direktnachricht. Voraussetzung: Eigenkreation, 64×64 PNG, Minecraft-kompatibel.

Sicherheit: Alle eingereichten Skins werden vor dem Upload auf Schadcode geprüft. Es werden ausschließlich PNG-Dateien akzeptiert – keine ausführbaren Dateien, keine Skripte.
