Datenschutz

Transparenz ist uns wichtig. Hier steht genau, was diese Seite speichert – und was nicht.

Diese Website

🔒 Kein Tracking

Diese Website verwendet keine Cookies, keine Zählpixel, keine Analyse-Skripte. Es gibt keine Session-IDs, keine User-Profile und keine Werbenetzwerke.

👤 Keine personenbezogenen Daten

Es werden keine IP-Adressen geloggt, keine Browser-Fingerprints erstellt und keine Formulardaten gespeichert. Die Website ist statisch (GitHub Pages) – es gibt keinen Server, der Daten entgegennehmen könnte.

📊 Live-Status

Die Status-Anzeige ruft api.mcsrvstat.us auf. Dabei wird die Server-Adresse übermittelt. Der Dienst speichert keine Daten über die Abfrage hinaus.

📁 Hosting

Auslieferung über GitHub Pages. GitHub verarbeitet Verbindungsdaten (IP, User-Agent, aufgerufene Seite) – technisch notwendig. Es gelten die GitHub-Datenschutzrichtlinien. Keine weiteren externen Dienste.

📧 Kontakt

Kein Kontaktformular, keine E-Mail-Erfassung. Bei Fragen im Spiel oder über den etablierten Kommunikationsweg melden.

Sicherheit

🛡️ Keine Angriffsfläche

Diese Website besteht aus statischem HTML/CSS/JS:

  • Keine Datenbank
  • Kein Login
  • Keine Server-seitige Ausführung (PHP, Node.js o.Ä.)
  • Keine Cookies
  • Keine Drittanbieter-Skripte
  • HTTPS (TLS) via GitHub Pages

🎮 Minecraft-Server

Der MINX-Server läuft isoliert mit Fabric. Regelmäßige Updates. Zugang nur für autorisierte Spieler. Keine Passwort-Logs.
