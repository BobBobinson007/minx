Datenschutz & Sicherheit

Diese Seite erklärt, welche Daten diese Website erhebt, wie sie geschützt werden – und vor allem: welche Daten nicht erhoben werden.

Datenschutzerklärung

🔒 Kein Tracking

Diese Website verwendet keine Cookies, keine Tracking-Pixel, keine Analytics-Dienste (kein Google Analytics, kein Matomo, kein Plausible). Es gibt keine Session-IDs, keine User-Tracking, keine Werbung.

👤 Keine personenbezogenen Daten

Wir erheben, speichern und verarbeiten keine personenbezogenen Daten. Es werden keine IP-Adressen geloggt, keine Browser-Fingerprints erstellt und keine Formulardaten gespeichert. Die Seite ist rein statisch (GitHub Pages) – es gibt keinen Server, der Daten entgegennehmen könnte.

📊 Server-Status-Abfrage

Die Live-Status-Anzeige ruft den öffentlichen Dienst api.mcsrvstat.us auf. Dabei wird die Server-Adresse wohixtkjsylk3md2.myfritz.net übermittelt. Dieser Dienst speichert keine Verbindungsdaten über den Abfragezeitpunkt hinaus.

📁 Externe Dienste

Diese Seite wird über GitHub Pages ausgeliefert. GitHub verarbeitet dabei die üblichen HTTP-Verbindungsdaten (IP, User-Agent, aufgerufene Seite). Dies ist technisch notwendig und fällt unter die GitHub-Datenschutzerklärung. Es werden keine weiteren externen Dienste eingebunden.

📧 Kontakt

Diese Seite bietet kein Kontaktformular und keine E-Mail-Erfassung. Bei Fragen zum Datenschutz oder zur Server-Sicherheit wende dich bitte an einen Admin im Spiel oder über den etablierten Kommunikationsweg.

Sicherheitshinweise

🛡️ Diese Website

Die Website besteht ausschließlich aus statischem HTML, CSS und JavaScript. Es gibt:

  • 🔐 Keine Datenbank
  • 🔐 Kein Login/Passwort-Formular
  • 🔐 Keine PHP, Node.js oder Server-seitige Ausführung
  • 🔐 Keine Cookie-Speicherung
  • 🔐 Keine Drittanbieter-Skripte (außer mcsrvstat.us API für Status)
  • 🔐 Keine Werbung
  • 🔐 HTTPS-verschlüsselt (via GitHub Pages)

🎮 Der Minecraft-Server

Der MINX-Server läuft in einer isolierten Java-Umgebung mit Fabric. Es werden regelmäßig Sicherheitsupdates eingespielt. Zugang haben nur autorisierte Spieler. Der Server logged keine Passwörter oder persönliche Daten.

⚠️ Haftungsausschluss

Diese Website wird ohne Gewähr bereitgestellt. Alle Inhalte dienen der Information der Server-Community. Es besteht kein Anspruch auf Verfügbarkeit oder Richtigkeit der angezeigten Daten.
